# Project Context

## Project

My Organizer (CSW.AI.OS)

Local web application used by V&V engineers to:

- Open Excel workbooks
- Manage tasks
- Manage CCRs
- Track TODO items
- Record notes
- Submit feedback

## Technology Stack

Backend:
- Python
- openpyxl (read only)
- Excel COM (writes)
- Microsoft Graph

Frontend:
- HTML
- CSS
- Vanilla JavaScript
